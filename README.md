this python program is a security tool which provides different security functions through the menu options.
1- security event counter 
-asks for a password 10 times
-counts corrects and incorrect password
-it calculates a percentage of the incorrect passwords
-it then displays an alret when the password goes over 50%

2- brute force simulation
-uses a predefined password
-maximum attempts are five
-counts the password guesses
-stops when password is found or attempts are done

3- login authentication
-requests the username and password
-only allows three failed attempts
-it then shows account frozen after 3 attempts

4- exit
-it shows a thank you message and shuts the program

-how to run the code 
-open terminal in the folder and type :
python3 security_tool.py
